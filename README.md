A make.fun entry for **Famous Last Words at 1 Percent**: the funniest
one-line farewell a phone could say as its battery hits 1 percent.

`main.py` writes the phone's last words to `/output/entry.txt` — a single
line of at most 199 characters.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
